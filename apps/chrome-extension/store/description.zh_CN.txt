COMO – 加密货币价格追踪与比特币实时行情

一键查看 11 家交易所的比特币、以太坊等加密货币实时价格 — 支持价格提醒、持仓追踪、K线图，并可在工具栏显示实时币价。

📈 11 家交易所实时行情
COMO 接入了十一家全球及韩国主流交易所。价格通过 WebSocket 实时推送，每笔成交都会即时更新到表格中。一秒切换交易所和市场。

🔔 价格提醒
为任意币种设置目标价，价格穿越目标价时即发送桌面通知。死区（deadband）选项可避免价格在目标价附近来回波动时重复提醒。点击通知即可在交易所打开该币种。还可以接收韩国交易所新上币、24 小时大幅涨跌和泡菜溢价阈值提醒。

💼 持仓
添加你的持仓（币种、数量、均价），实时查看总市值和盈亏。总额可用 15 种本地货币显示。

🧭 市场洞察
• 恐惧与贪婪指数、BTC 市占率和 BTC 资金费率一目了然
• 跨交易所价差：看清同一币种在哪里最便宜、哪里最贵
• 韩国交易所泡菜溢价

🐸 DEX 与 Meme 币
按代币符号或合约地址搜索任意代币（由 DexScreener 提供支持）并加入自选列表 — 即使尚未在中心化交易所上线也可以。

🕯 K线图
支持所有交易所从 1 分钟到 1 个月的 K 线图，直接在弹出窗口中查看。

⚡ 极速体验
• 工具栏图标实时显示币价（可选任意币种）
• 侧边栏模式，浏览网页时也能随时看行情
• 快捷键：Ctrl + Space (Windows, Linux) / Cmd + Shift + Space (Mac)
• 自选置顶、深色模式、紧凑和宽屏布局
• 绿涨或红涨配色可选

🌍 支持 10 种语言
界面默认跟随浏览器语言，也可以随时在设置中切换。

🔒 隐私
COMO 默认仅从交易所和行情 API 读取公开市场数据，不会读取你访问的网页；你的设置、提醒和持仓都只保存在你的浏览器中。无需注册账号或登录。可选的账户同步会使用你填写的只读 API 密钥，密钥仅保存在你的浏览器中，且只发送给对应的交易所。
