📈 실시간 시세
국내 거래소와 해외 대형 거래소의 시세를 웹소켓으로 실시간 반영합니다. 거래소와 마켓은 클릭 한 번으로 바꿀 수 있습니다.

🔔 지정가 알림
원하는 가격에 도달하면 데스크톱 알림을 보내고, 알림을 누르면 해당 거래소 거래 화면으로 이동합니다. 재알림 범위 설정으로 잦은 알림을 막을 수 있습니다. 국내 거래소 신규 상장, 24시간 급등락, 김치 프리미엄 기준 도달 알림도 받을 수 있습니다.

💼 보유 자산
코인·수량·평균가를 등록하면 총 평가금액과 손익을 실시간으로 계산합니다. 15개 통화로 합산해 볼 수 있습니다.

🧭 시장 인사이트
공포·탐욕 지수, BTC 도미넌스, BTC 펀딩비와 거래소 간 가격 차이를 한 화면에서 확인합니다.

🐸 DEX·밈코인
심볼이나 컨트랙트 주소로 토큰을 검색해 관심 목록에 추가할 수 있습니다.

⚡ 편의 기능
툴바 아이콘에 실시간 가격 표시, 사이드 패널 모드, 다른 창 위에 띄우는 미니 창, 조용한 모드, 즐겨찾기 상단 고정, 다크 모드, 와이드 화면, 상승·하락 색 설정을 지원합니다.

👑 단축키 안내
창 열기/닫기: Alt + Shift + C (Windows, Linux) / Cmd + Shift + Space (Mac)

🔒 개인정보
기본적으로 거래소·시세 공개 API만 조회하며, 방문하는 웹페이지를 읽지 않습니다. 설정·알림·보유 자산은 브라우저에만 저장됩니다. 거래소 계정 연동(선택)을 켜면 직접 입력한 읽기 전용 API 키를 쓰며, 키는 브라우저에만 저장되고 해당 거래소에만 전송됩니다.
