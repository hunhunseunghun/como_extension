COMO 개인정보처리방침

시행일: 2026-10-09

1. 수집하는 정보

COMO는 개인정보를 수집하거나 개발자의 서버로 전송하지 않습니다. 회원가입이 없고, 광고·분석 도구도 쓰지 않습니다.

2. 브라우저에 저장되는 정보

설정, 즐겨찾기, 알림 규칙, 보유 자산 정보는 사용자의 브라우저(chrome.storage)에만 저장되며 외부로 전송되지 않습니다.

3. 외부 서비스 호출

시세·환율·지수·뉴스 등 공개 데이터를 가져오기 위해 업비트, 빗썸, 바이낸스 등 거래소와 데이터 제공처의 공개 API를 호출합니다. 방문하는 웹페이지의 내용은 읽지 않습니다.

4. 거래소 계정 연동(선택)

사용자가 직접 입력한 읽기 전용 API 키는 브라우저에만 저장되며 해당 거래소에만 전송됩니다. 거래 권한이 있는 키는 거부합니다.

5. 제3자 제공

개발자는 사용자 정보를 제3자에게 제공하거나 판매하지 않습니다.
