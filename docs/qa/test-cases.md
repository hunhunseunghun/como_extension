# COMO 확장 수동 검증 TC (3.1.0)

빌드한 확장(`apps/chrome-extension/dist`)을 Chromium에 로드한 뒤, 사람이 쓰는 것처럼 화면을 보며 클릭·입력해 확인한다.
팝업은 420×430, 와이드는 800×600, 사이드 패널은 `?view=sidepanel`로 연다. 기본 언어는 한국어다.

검증일: 2026-10-03 · 방법: Playwright로 띄운 Chromium 창을 한 동작씩 조작하고 스크린샷으로 확인

결과: ✅ 통과 · ❌ 실패 · ⚠️ 동작은 하지만 확인할 점 있음 · ⏭️ 이 환경에서 확인 불가

## 지정가 알림 패널 개편 (2026-10-03)

- 거래소 드롭다운(로고만) → 거래소 칩 9개. 바꾸면 같은 코인을 그 거래소 기본 마켓에서 찾는다
- 검색: 결과에 현재가 표시, Enter로 선택, 일치·앞글자(초성 포함) 우선, 결과 없음 안내, 첫 Esc는 목록만 닫음
- 선택 종목 타일: 실시간 현재가·변동률
- 목표가: 소수 입력 가능(작은 가격이 0이 되던 문제 해결), 빠른 설정 ±1·5%·현재가, 방향(▲ 오르면/▼ 내리면)과 현재가 대비 % 안내
- 데드밴드 → "재알림 범위" 0·1·3·5·10% 선택 + 한 줄 설명(툴팁 제거)

## 남은 개선 제안

- 업비트 입출금 상태(계정 연동 사용자)는 실제 키가 있어야 확인 가능
- 스토어 업로드 스크립트는 API 자격 증명을 발급해 .env.store에 넣은 뒤 첫 실제 업로드로 확인 필요
- API 키 암호화 저장은 하지 않았다. 같은 프로필에 키와 암호화 키가 함께 있어 실효가 작고, 대신 거래 권한 키 거부·세션 보관을 넣었다
- 업비트 공지 알림의 권한 요청과 새 기능 안내 카드는 자동 테스트가 어렵다(수동 확인 필요)
